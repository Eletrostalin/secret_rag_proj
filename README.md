🏥 HIPAA RAG-сервис — интеллектуальный поиск по нормативному документу

Проект представляет собой полноценную реализацию Retrieval-Augmented Generation (RAG) системы для точного поиска и генерации ответов на вопросы по официальному документу HIPAA Administrative Simplification Regulation Text (март 2013).

Сервис сочетает точный поиск, переформулировку запросов, векторное и семантическое сопоставление, логическую фильтрацию и генерацию финального ответа на базе LLM.

🎯 Цель проекта

Создать юридически точную и интерпретируемую систему вопрос-ответ по HIPAA, способную:
	•	Извлекать релевантные параграфы нормативного акта
	•	Работать с неточным языком пользователя
	•	Возвращать юридически корректный и обоснованный ответ
	•	Обеспечивать возможность цитирования источника
 

🧠 Архитектура решения

🔎 Поисковый стек
	•	BM25 — базовый лексический поиск
	•	Векторный поиск — на основе модели intfloat/multilingual-e5-large
	•	Cosine rerank — фильтрация по схожести
	•	LLM rerank — финальное логическое ранжирование (GPT-4.1)

📌 Обработка запросов
	•	Query rewriting — переформулировка запроса через GPT-4o
	•	Query expansion — добавление синонимов и уточнений
	•	Quote mode — если пользователь ссылается на конкретный параграф (§), поиск ограничивается только этим разделом
	•	LLM-based filter — дополнительная проверка релевантности

💬 Ответ
	•	Сбор финальных чанков
	•	Построение контекста
	•	Генерация ответа моделью gpt-4.1 с возможностью ссылок на документ
 
📦 Стек технологий
	•	Python 3.10+
	•	FastAPI — backend API
	•	Gradio — UI для пользователя
	•	SQLAlchemy — работа с PostgreSQL
	•	pgvector — хранение векторных эмбеддингов
	•	Docker — контейнеризация
	•	OpenAI API — модели GPT для генерации и обработки

⸻

⚠️ Особенности
	•	Сервис работает только с одним PDF-документом — HIPAA Regulation Text (март 2013)
	•	Весь пайплайн парсинга, чанкинга и извлечения построен на жёсткой структуре документа
	•	Замена или изменение документа потребует полной перестройки логики
